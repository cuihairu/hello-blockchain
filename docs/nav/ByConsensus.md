# Navigate by consensus algorithm

52 algorithms in one table: **first appearance → which layer → what it solves → which chains use it**. Rows are ordered by first-appearance year; the algorithm column links to deep-dive pages, the chain column to chain pages. For the year-by-year evolution of algorithms, read the [consensus algorithm timeline](/consensus-timeline); for chains ordered by mainnet launch, see [navigate by time](/nav/ByTime); the four-layer attribution is expanded in the [layered architecture](/layers/Layers).

## How to read it

- **Many algorithms in the same year** (densest in 2016-2018) tell you the same story: the three-phase structure of BFT keeps being reinvented in permissionless networks — the leader-election method differs, the skeleton does not.
- **Layer** is annotated against the [four-layer model](/layers/Layers); nearly every algorithm sits in the settlement layer, and the exceptions (PoH as a time layer, Sequencing as a compute-layer entry point, SPoRA's storage incentives) are worth reading separately.
- **What it solves** is the one-sentence compression; the full version and citations live in the "four elements" block at the top of each deep-dive page.

# Snowball

Snowball 是 Team Rocket（Avalanche 团队化前的化名）2018 年白皮书提出的**无领导、亚采样、概率性**共识协议族，是 Avalanche 共识的核心构件。它与经典 BFT 全网广播投票完全不同：每轮只随机询问少量节点，重复后偏见收敛。

## 协议族演进

1. **Slush**：节点收到交易后发起查询，随机采样 $k$ 个节点询问颜色，若多数给出另一色则变色，重复 $m$ 轮。无状态、有偏随机游走。
2. **Snowflake**：在 Slush 上加"连续计数器"——连续 $\beta$ 次采样多数一致才接受，抗瞬时扰动。
3. **Snowball**：进一步加"置信度累加器"：每次采样多数的颜色增加其置信度，另一色清零；置信度达 $\beta$ 后锁定（accept）。参数 $(k, \alpha, \beta)$ = （采样数、多数阈值、计数阈值）。
4. **Snowman**：在 Snowball 之上封装成链式（区块序）共识，是 Avalanche 平台出块引擎。

## 性质

- **概率安全**：诚实节点被"翻转"接受冲突交易的概率随 $\beta$ 指数下降——与 PoW 的概率最终性同型，但不需要算力。
- **无领导者**：没有 proposer/leader 角色，天然抗女巫程度取决于验证人准入（Avalanche 主网用质押权重加权）。
- **通信量小**：每轮只与 $k$ 个节点通信（$k \approx 20$），消息不随 $n$ 爆炸，万级节点可用。
- **并行性**：不同交易独立并发共识，冲突交易间才互斥，天然高并发。

## 与经典 BFT 的对比

确定性 BFT 给出"绝对不可逆 + 轮次有限"的保证；Snowball 给出"参数化概率 + 无限轮收敛"的保证，换来更低的通信成本与更好的横向扩展。Avalanche 主网实测秒级最终性，理论上限受参数与网络质量影响。

# HoneyBadgerBFT

HoneyBadgerBFT（HBBFT）是 Miller 等人 2016 年提出的**首个实用异步原子广播协议**，名字致敬"蜜獾不怕慢"：不依赖任何网络时序假设，无论消息多慢、是否分区，安全与活性都保持。

## 关键思想

1. **交易顺序去中心化**：不指定某个节点打包顺序，而是让各节点各自提议交易，通过**异步共同子集（ACS）**协议就"一组交易"达成一致——打包顺序由共识内生决定。
2. **阈值加密隐藏内容**：交易先以阈值加密提交，确认集合后才联合解密。这带来两个好处：审查者看不到内容无法针对性干预（抗审查）；避免"偷看别人交易再搭车"。
3. **随机化 ABA**：异步二进制共识（Asynchronous Binary Agreement）用共同随机硬币（共掷硬币，基于阈值签名/共享随机数）打破 FLP 僵局，保证以概率 1 终止。

## 技术构件

- **RBC（可靠广播）**：基于 erasure coding 的异步可靠广播，节点带宽均摊。
- **ABA（异步二进制共识）**：Mostefaoui 式多轮投票 + 共享硬币。
- **ACS**：N 个 RBC + ABA 组合，取全体提议的交集。
- **阈值签名/加密**：$f+1$ 或 $t$ 份额聚合，控制消息量与隐私。

## 性能与特点

- **吞吐与最慢节点解耦**：经典 BFT 里 leader 等最慢副本，HBBFT 中任何节点先到的交易先入集——吞吐由网络总带宽决定。
- **消息复杂度 $O(N^2)$**，节点规模仍受限（数百级），适合联盟链。
- 实现参考：poanetwork/hbbft（Rust）、afleck/hbbft 等实验实现；POA Network 曾用于 xDai 相关研究链。

## 适用场景

网络环境恶劣、节点互不完全信任、又不想要 PoW/PoS 经济博弈的场合：联盟链、隐私交易池、去中心化随机数生成（与阈值 BLS 结合）。

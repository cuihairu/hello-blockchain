# PoW

工作量证明（Proof of Work, PoW）要求节点投入真实世界的计算成本来竞争记账权，以此把"作恶"变得比"诚实"更贵。它最早用于对抗垃圾邮件（Hashcash），由中本聪在比特币中发扬光大，成为第一个无许可公链的安全基石。

## 基本原理

矿工需要寻找一个区块头，使其双重 SHA-256 哈希小于当前难度目标：

```
H( block_header ) < target
```

由于哈希输出不可预测，寻找合格区块头的唯一办法是不断修改 Nonce 暴力尝试——这个过程即"挖矿"。找到合格区块后广播全网，其他节点验证哈希即接受（验证远快于寻找）。

## 难度调整

- 比特币每 **2016 个区块（约两周）** 调整一次难度，使出块间隔稳定在 **约 10 分钟**：实际出块快了就调高难度，慢了就调低。
- 难度调整使 PoW 对算力波动自稳定，也让"算力 = 安全预算"成为可预期的量。

## 最长链规则与安全性

- 节点总是接受**累计难度最高**的链（俗称最长链规则）。分叉时，算力最终会向一条链集中，另一条被抛弃。
- 攻击者要重组已确认的交易，必须以超过全网 50% 的算力持续产出更重的链（见[大算力攻击](/hacking/51Attack)）；攻击消耗的电费即是攻击成本，而诚实挖矿的收益使多数算力倾向于合作。

## 优点

- **无许可、准入中性**：不需要身份或质押，接入算力即可参与，抗女巫能力来自物理世界成本。
- **久经验证**：比特币主网 2009 年至今未被成功重组。
- **finality 模型简单**：无需网络级投票，节点本地验证最长链即可。

## 缺点

- **能耗巨大**：全网算力消耗的电力只服务于哈希竞争。
- **确认慢**：比特币约 6 个确认（约 1 小时）才达到足够低的回滚概率。
- **算力集中化**：矿池使小算力流动性化，头部矿池算力占比可观；ASIC 专用硬件进一步抬高参与门槛。
- **吞吐量低**：出块间隔与区块大小限制了 TPS。

## 代表应用

Bitcoin、Litecoin（Scrypt）、Monero（RandomX，抗 ASIC）、Chia 之前的大部分早期公链；比原链曾使用兼容通用计算的 Tensority。

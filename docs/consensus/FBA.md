# FBA

联邦拜占庭协议（Federated Byzantine Agreement, FBA）由 Stellar 首席科学家 David Mazières 在 2015 年的 SCP 白皮书中提出。与 PBFT 类协议"预先固定成员名单"不同，FBA 让**每个节点自己选择信任谁**，全局的信任关系网络自发形成共识仲裁。

## 核心概念

1. **仲裁切片（Quorum Slice）**：某节点信任的一组节点集合。节点认为某声明为真，当且仅当它的每个仲裁切片中都有足够成员认可该声明。
2. **法定人数（Quorum）**：满足所有成员切片要求的节点集合——切片是"个人的信任"，法定人数是"全局的共识群体"。
3. **联邦化准入**：无全局成员表；新节点自行声明切片即可加入，去中心化体现在"切片选择"上。

## 安全的关键：切片的交织性（Intertwine）

- 若各节点的切片互相重叠、交织良好，恶意小团体无法单独满足足够多的切片，共识保持安全。
- 若切片选择不佳（例如大家都只信同一家交易所节点），系统退化为事实上的中心化——**FBA 的安全性由用户的信任选择决定**，这是它最大的优点也是最难的工程问题。

## 与 PBFT 的对比

| 维度 | PBFT | FBA (SCP) |
| --- | --- | --- |
| 成员 | 固定、预先知晓 | 开放、联邦化自选 |
| 通信 | 全网广播 $O(n^2)$ | 切片内传播，成本低 |
| 安全前提 | < 1/3 拜占庭 | 切片交织 + 非劣化节点 < 阈值 |
| 活性 | 部分同步保证 | 阻塞事件（blocking）触发推进 |

## 应用

**Stellar Consensus Protocol（SCP）** 是 FBA 的唯一大规模生产实现（见 [Stellar](/chains/Stellar)）；Ripple 的瑞波协议共识（RPCA）是更早的"唯一节点列表（UNL）"式近亲，但 UNL 由网络层面统一指定，去中心化程度常受质疑。

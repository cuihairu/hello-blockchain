# ABFT

异步拜占庭容错（Asynchronous BFT, ABFT）指在**异步网络模型**（消息延迟无上界、无全局时钟）下仍能保证安全与活性的拜占庭容错协议。它的理论意义在于：真实互联网最接近异步模型，而经典 PBFT 依赖部分同步假设（超时驱动）。

## 理论背景

- **FLP 不可能定理**（1985）：纯异步 + 确定性 + 容忍一个崩溃节点的系统中，不存在必然终止的共识协议。
- 突破口是**随机化**：引入随机源后，协议以概率 1 终止。ABFT 协议正是这条路线的工程化。

## 代表协议

1. **HoneyBadgerBFT**（2016）：首个实用异步原子广播协议，用阈值加密隐藏交易内容、随机化解耦"打包顺序"，吞吐不受最慢节点拖累（见 [HoneyBadgerBFT](/consensus/HoneyBadgerBFT)）。
2. **Dumbo 系列**（2019-2021）：优化异步共识的期望消息复杂度，成为异步 BFT 的性能标杆。
3. **Avalanche 共识族**：雪崩式子采样投票，可在无领导者下收敛，常被归入"无领导者概率安全"路线，与经典 ABFT 并列讨论（见 [Avalanche](/consensus/Avalanche)）。

## 技术构件

- **阈值签名**：$t+1$ 份签名聚合成一个可验证签名，消息量与节点数解耦。
- **可靠广播（RBC）**：异步环境下把一个值可靠地广播给全体，配合 erasure code 降低带宽。
- **共同子集（Common Subset）**：各节点提案不同时，经异步二进制共识（ABA）就同一个集合达成一致。

## 优点与代价

**优点**：不做同步假设，抗网络分区与慢节点攻击（时不我待的"自适应作恶"难以制造超时误判）；时延由最快节点决定而非最慢节点。

**代价**：密码学构件（阈值签名、秘密分享）计算开销大；协议复杂度高，工程实现远少于部分同步 BFT。

## 应用

HoneyBadgerBFT 用于 POA Network 的一些实验链与隐私交易系统；Dumbo 系列被多个国内联盟链项目研究采纳；Avalanche 平台将其思想发展为 Snowman/Avalanche 共识。

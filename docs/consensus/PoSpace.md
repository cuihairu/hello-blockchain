# PoSpace

空间证明（Proof of Space, PoSpace）要求证明者花费存储资源来换取记账资格：证明者预先构造巨大的、只能通过占用磁盘才能快速应答的挑战-响应数据结构，网络随机出题，谁持有"最接近答案"的数据谁赢。它是 Chia 区块链的核心构件，与 [PoT](/consensus/POT) 配对使用。

## 四要素

- **在哪一层**：[结算层](/layers/Settlement) —— 按存储空间分配记账权，与 [PoT](/consensus/POT) 配对使用（Chia 形态）
- **解决什么**：用磁盘空间替代算力——证明者预先构造只能靠占用磁盘才能快速应答的挑战-响应数据结构，把作恶成本锚定在存储上
- **解决得怎么样**：能耗比 PoW 低几个数量级、闲置硬盘可复用；代价是绘图集中化（大农场收购容量）、绘制过程的写入量是真实的环境成本、空间可被快速买卖
- **出处**：Dziembowski 等《Proofs of Space》CRYPTO 2015；Chia 白皮书 2019

## 基本原理（Chia 实现）

1. **绘图（Plotting）**：矿工生成以自己密钥为根的 chialisp 哈希证明表（plot 文件，常见 101 GiB 的 k32），内含大量按特定图结构（基于 RY Pie graphs）存储的"质量字符串"。
2. **挑战**：每个 slot（约 18.75 秒）网络公布挑战，矿工在 plot 中查询 64 个 quality，取最小者。
3. **证明与过滤**：quality 与难度共同决定是否有资格出块；有资格者再创建区块并附上空间证明。验证方无需磁盘即可验证证明（约占 plot 的小比例数据）。
4. **防作弊**：plot 绑定矿工密钥，复制 plot 到多机不增加中签率（奖励指向同一 key）；重绘时间远长于 slot 时长，临时"现画现卖"不可行。

## 特点

**优点**：能耗比 PoW 低几个数量级；硬盘是通用资产，准入门槛低；安全性论证有严谨的密码学文献（Abusalah et al. 的 PoSpace 形式化）。

**缺点**：存储军备竞赛（NAS 短期挖矿潮）；replotting 攻击与"经济上反复重绘"的边界依赖 PoT 时序约束；长期闲置盘的回收与二手市场扰动。

## 与同类证明的关系

- [PoC](/consensus/POC)（Burstcoin）是先行的工程实现，PoSpace 是其密码学强化版。
- Filecoin 的 PoRep/PoSt 用存储证明**提供存储服务**（有用的存储），而 PoSpace 只把存储当作抽奖彩票，两者动机不同。

# PoS

权益证明（Proof of Stake, PoS）用"经济质押"替代"算力竞争"：验证人锁定一定数量的原生代币作为保证金，按质押权重被选中出块或投票；作恶者的质押可被罚没（slashing），诚实参与者获得增发与手续费奖励。

## 基本原理

1. **质押准入**：节点提交质押交易锁仓（如 Ethereum 要求每验证人 32 ETH）。
2. **验证人选择**：协议按权重/随机数（如 VRF、RANDAO + VDF）在每轮选出提议者与证明者，权重通常与质押量成正比。
3. **出块与投票**：提议者打包区块，其余验证人对区块签名投票，达到阈值（通常 2/3）后确认。
4. **奖惩**：出块与投票获得奖励；双签、长时间离线、环绕投票等行为触发罚没。

## 与 PoW 的对比

| 维度 | PoW | PoS |
| --- | --- | --- |
| 女巫防御成本 | 电力 + 硬件 | 锁仓代币的机会成本 |
| 能耗 | 极高 | 极低（Ethereum 合并后约降 99.95%） |
| 攻击成本 | 电费 | 代币贬值风险 + 罚没 |
| 最终性 | 概率性 | 多数实现为确定性（BFT 投票） |
| 中心化风险 | 矿池/ASIC | 富者愈富、交易所托管质押 |

## 关键设计难题

1. **Nothing-at-Stake（无利害攻击）**：PoW 分叉需要分裂算力，PoS 复制签名却零成本——验证人可以在所有分叉上同时投票。解法：罚没规则惩罚在冲突区块上双签的行为。
2. **Long Range Attack（长程攻击）**：早期验证人的旧密钥可以从创世区块重造一条替代链。解法：检查点、弱主观性（新节点必须从近期可信状态同步）。
3. **冷启动代币分布**：PoS 的初始分配依赖创世分配或从 PoW/空投迁移，公平性常有争议。

## 代表实现

- **Ethereum**：Gasper（Casper FFG + LMD GHOST），信标链管理 32 ETH/验证人、罚没与退出队列。
- **Cardano**：Ouroboros 系列论文， epoch 时隙制 + VRF 选主。
- **Cosmos 生态**：Tendermint BFT 之上叠加质押（ bonded POS）。

# TBFT

TBFT 是长安链（ChainMaker）采用的拜占庭容错共识算法，设计上与 Tendermint 同源：以 BFT 三阶段投票实现秒级确定性出块，并针对联盟链做了性能与工程化改造。

## 基本流程

1. **Propose**：按权重轮换的 leader 打包交易生成提案区块。
2. **Prevote / Precommit**：验证人对提案两轮投票，各收集 $2f+1$ 票形成 QC；超时或收到冲突提案进入下一轮换 leader。
3. **Commit**：区块获得 commit QC 后立即落账，**最终性确定**，无回滚窗口。

## 特点

- **确定性最终 + 高吞吐**：相比 PBFT 减少了一阶段消息（合并 prepare/commit 投票），在 100 节点内保持数千至万级 TPS。
- **与流水线结合**：区块 $k$ 的投票可以流水化覆盖区块 $k-1$，出块间隔与确认时延进一步压缩。
- **可插拔**：长安链将 TBFT、RAFT、Solo 并列为可切换的共识模块，按联盟规模与信任模型选择（BFT 换取安全冗余，RAFT 换取极低时延）。

## 与 Tendermint 的异同

相同点：三阶段结构、锁定机制、轮次换主、+2/3 阈值。差异点：TBFT 面向许可集合（证书准入，CA 体系），不做公开质押与罚没；消息聚合与持久化层针对长安链存储引擎优化。

# Yuma Consensus（Bittensor）

Bittensor 的 **Yuma Consensus** 回答一个少见的问题：**主观服务质量怎么共识化？** miner 产出子网商品（预测、图像、文本），验证者各自打分，链上用质押加权的中位数裁剪把「主观评价」压成一个不可串谋的权重——不验证执行结果，只共识「大家认为你做得怎么样」。

## 四要素

- **在哪一层**：[结算层](/layers/Settlement) —— 底层出块在 subtensor（Substrate 链，现行 PoA：Aura 出块 + GRANDPA 终局），Yuma 是**层上的评价共识**，不替代出块共识
- **解决什么**：服务质量不可形式验证（不像 ZK 可证），但需要可共识的排序与奖励分配，同时抗验证者串谋
- **解决得怎么样**：机制上优雅（中位数裁剪 + 偏离共识者失去分红），是「主观效用」领域唯一的成体系答案；代价是流量与评分权都经过验证者——「所有 miner 流量只走验证者」形成评分寡头，与支付方直接驱动的设计取向相反。公开事故：未找到公开记录
- **出处**：Bittensor 白皮书（Yuma Consensus、协作威胁分析章节）；官方文档 concepts/internals（<https://docs.bittensor.com/>）

## 核心机制

- **打分 → 加权中位数 → 裁剪**：每 epoch（tempo，默认 360 块 ≈ 72 分钟）验证者对 miner 执行 set-weights；链按验证者质押加权聚合，取 κ（典型 0.5）比例质押背书的最大权重并**裁掉其上权重**——少数派帮派推高的分数被削掉。
- **偏离共识被惩罚**：打分不达共识的诚实验证者失去该轮分红（forfeit rewards），帮派投票的质押被 slash——「打分权」本身被经济化约束。
- **抗串谋边界**：协议声称在「多数质押诚实」下稳健，能抗最多 50% 权重的串谋；超过即失效。
- **燃烧式注册**：多数子网注册需付**不退**的浮动注册费——没有仲裁成本的女巫闸门，也没有惩罚梯度。
- **经济侧**：基础发行按 EMA 需求份额分配到子网；每 tempo 按 18% 子网所有者 / 41% miner / 41% 验证者及其质押者分配；2025-02 起子网 alpha 独立上限与减半曲线（dTAO）。

## 与同族协议的差异

| 协议 | 关系 | 关键差异 |
| --- | --- | --- |
| [Livepeer](/consensus/DPOS) | 同类（服务验证） | Livepeer 用**概率抽样验证**产出可证结果，Yuma 用**打分共识**处理主观产出 |
| [DPOS](/consensus/DPOS) | 对照 | DPoS 用质押选出代表投票；Yuma 的验证者是「评价权」持有者，链上还要裁剪 |
| [GHOST](/consensus/GHOST) | 对照 | 都靠权重选优，但 Yuma 的权重是评价分不是链长 |
| [BFT](/consensus/BFT) | 边界 | 传统 BFT 要求提议值可验证一致，Yuma 的提议是主观分数——所以只能抗 50% 而非 1/3 |

## 失败模式

- **评分寡头**：所有 miner 的流量与可见性只经过验证者，评分权集中在质押最多者——这是协议结构内生的，不是实现缺陷。
- **主观性的天花板**：中位数裁剪只能削掉极端分，无法防止「整体共识性低估」——系统性偏差会被当成事实写入排名。
- **注册费与流动性**：燃烧式注册把小额参与者挡在门外，子网满员后新矿工靠逐出机制挤入，边际成本不透明。
- **底层仍是许可链**：subtensor 现行 PoA，计划迁移 NPoS 属路线图（时间未定）——「主观共识」跑在许可出块之上。

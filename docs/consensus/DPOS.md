# DPoS

委托权益证明（Delegated Proof of Stake, DPoS）是 PoS 的代议制变体：全体持币人不直接出块，而是投票选出固定数量（通常 21~101 个）的"代表/超级节点"，由这些代表轮流、高效地生产区块。

## 基本原理

1. **投票选出代表**：持币人按持币量加权投票（或抵押投票），得票前 N 名成为出块节点。
2. **轮流出块**：代表按预定顺序（轮转或随机洗牌）出块，出块间隔通常在秒级（EOS 0.5 秒、BTS 约 2 秒）。
3. **持续问责**：不出块、频繁掉线的代表会被跳过；声誉恶化会被投票换掉。

## 特点

**优点**

- **吞吐量高**：验证人少、通信复杂度低，区块时间短，适合高 TPS 应用。
- **确认快**：EOS 采用 BFT 式确认（Irreversibility），交易数秒内不可逆。
- **治理闭环**：代表身份公开，作恶直接承受声誉与被投出去的代价；EOS 曾以宪法/仲裁机制处理争议。

**缺点**

- **去中心化程度受限**：少数验证人易形成卡特尔、互投联盟，投票率低时"富者愈富"更明显。
- **治理攻击**：选票交易（bribing）与交易所代持投票难以防范。

## 代表应用

- **EOS**：21 个超级节点（Block Producer），DPoS + BFT 最终性。
- **BitShares**：Daniel Larimer 最初提出的 DPoS 实现。
- **TRON**：27 个超级代表（Super Representative）。
- **Lisk、Ark** 等也采用 DPoS 变体。

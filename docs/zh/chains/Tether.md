# Tether 泰达币

Tether（简称USDT）并非一个独立的区块链项目，而是一种基于区块链技术的加密货币，被称为稳定币（Stablecoin）。稳定币的主要特点是其价格相对稳定，通常与法定货币（如美元）或其他资产（如黄金）挂钩，以减少波动性。以下是关于Tether项目的详细介绍：


## 白皮书与规范

无正式白皮书——以[官网透明度页](https://tether.to/en/transparency)与储备构成报告为准（BDO 意见书为鉴证而非全面审计）。USDT 2015 年起在 Omni 层发行，后扩展多链。

## 解决什么问题

链上需要法币锚定的结算单位——交易、汇兑、结算都要「不漂」的记账本位币（见[结算层](/zh/layers/Settlement)的计价职责）。

## 技术成果与贡献

- **最大稳定币发行方**：USDT 成为全链流动性底座，横跨 Omni、以太坊 ERC-20、TRON TRC-20 等标准。
- **多链发行与赎回通道**：把「发行方托管 + 多链映射」做成行业模板。
- **储备结构定期披露**：尽管争议不断，披露频率与细度在同类发行方中属高位。

## 局限与公开事故

- 中心化托管与冻结权（执法冻结事件频发）；储备透明度长期争议。
- 公开事故：2018-10 挤兑传闻致 USDT 短暂跌至 $0.90；2021-02 NYAG 罚 1850 万美元（储备误导陈述）；2021-10 CFTC 罚 4100 万美元（储备不实陈述）。

## 补充说明
### Tether 的基本概述

1. **稳定币的类型**：
   - Tether 最初是基于比特币区块链的Omni Layer协议发行的，后来发展为支持多种区块链网络，如以太坊（ERC-20协议）、TRON网络（TRC-20协议）和Algorand网络等。每种网络上的Tether都称为不同的代币，如USDT（ERC-20）、USDT（TRC-20）等。

2. **价格稳定机制**：
   - Tether的价格稳定机制主要依赖于其背后的资产储备。根据Tether的官方声明，每个USDT代币都应该与1美元等值的资产（如现金和现金等价物）挂钩，以保持价格稳定。

3. **流通和应用**：
   - Tether作为一种稳定币，广泛应用于加密货币市场，用于交易、支付和资金转移。其稳定性使得它成为加密货币交易所中主要的交易对和资金存储方式之一。

4. **审计和透明度**：
   - Tether公司声称定期接受独立审计，以验证其持有的资产与USDT流通量之间的对应关系。透明度和审计过程对于稳定币的用户和市场参与者来说至关重要，以确保稳定币的信任和可靠性。

5. **法律和监管**：
   - 作为市场上最流行的稳定币之一，Tether面临着来自监管机构的审查和法律约束。其公司在不同的法域内都有监管合规措施，以确保符合当地和国际的金融法规。

### Tether 的应用和影响

- **交易和支付**：Tether广泛用于加密货币市场的交易和支付，特别是在缺乏法定货币支持的交易所中，作为稳定的交易对和资金储备工具。

- **金融服务**：稳定币在全球范围内提供了便捷的跨境支付和结算解决方案，以及在金融服务中的应用潜力，如借贷和资产管理。

- **市场流动性**：作为加密货币市场中的主要流动性提供者之一，Tether对整个市场的稳定性和流动性都有重要影响。

总体而言，Tether作为一种稳定币，通过其价格稳定的特性和广泛的应用场景，在加密货币领域发挥着重要作用。然而，由于其背后的资产储备和法律合规等方面的关注，其未来的发展和影响也面临着多重挑战和变数。

# 链游经济设计

链游经济的结构性问题不是「游戏设计差」，而是**游戏经济与代币经济的耦合方式**。绝大多数链游的经济模型都依赖新玩家入场——产出代币的速率超过消耗速率时，代币必然贬值，抛压加剧，形成死亡螺旋。本专节梳理产出消耗闭环、防女巫设计、通胀模型与崩盘机制。

## 四要素

- **在哪一层**：[计算层](/zh/layers/Compute) + [服务发现](/zh/layers/ServiceDiscovery) —— 经济规则在合约层执行，资产标识在链上
- **解决什么**：链游需要在「游戏可玩性」与「经济可持续」之间找到平衡——产出代币激励玩家，但不能无限通胀
- **解决得怎么样**：双代币模型（治理 + 游戏）是主流方案，但绝大多数链游的经济模型仍是「后来者补贴先行者」；防女巫靠繁殖消耗与时间锁定，但无法阻止工作室批量生产
- **出处**：[BBC·Ronin Network: What a $600m hack says about the state of crypto](https://www.bbc.com/news/technology-60933174)、[Wikipedia·Axie Infinity](https://en.wikipedia.org/wiki/Axie_Infinity)、[Wikipedia·Decentraland](https://en.wikipedia.org/wiki/Decentraland)、[StepN 官网](https://www.stepn.com)

## 产出消耗闭环

链游经济的核心是**产出（faucet）与消耗（sink）的平衡**：

| 项目 | 产出方式 | 消耗方式 | 经济本质 |
| --- | --- | --- | --- |
| [Axie Infinity](/zh/chain-games/ChainGames) | 对战赚 SLP、繁殖新宠物 | 繁殖消耗 SLP+AXS、修复宠物 | 新玩家入场费补贴先行者 |
| [StepN](/zh/chain-games/ChainGames) | 跑步赚 GST | 升级/修复/开宝箱销毁 GST | 后来者买鞋补贴先行者跑步 |
| [The Sandbox](/zh/chain-games/ChainGames) | LAND 销售、SAND 产出 | SAND 购买 LAND/装备 | 虚拟地产投机 |
| [Decentraland](/zh/chain-games/ChainGames) | LAND 销售、MANA 产出 | MANA 购买 LAND/装备 | 虚拟地产投机 |

## 防女巫设计

链游的防女巫核心是**提高批量生产身份的成本**：

- **繁殖消耗**：Axie 的繁殖需要消耗 SLP+AXS，且繁殖次数越多消耗越高。经济上限制了无限繁殖，但工作室通过购买已有繁殖次数的宠物绕过限制。
- **时间锁定**：新宠物需要等待一段时间才能出售或繁殖，减缓了资金流转速度。
- **硬件绑定**：StepN 通过 GPS 验证跑步真实性，但无法阻止批量使用模拟器。
- **身份验证**：部分链游要求 KYC 或手机号绑定，但牺牲了匿名性。
- **链下经济**：部分链游把产出逻辑放在链下（中心化服务器），链上只记录所有权。这种设计牺牲了去中心化，但降低了女巫成本。

## 通胀模型

链游代币的通胀模型通常分三类：

- **固定总量 + 通胀增发**：治理代币（如 AXS）固定总量，游戏代币（如 SLP）无限增发。治理代币靠稀缺性支撑价格，游戏代币靠产出激励玩家。问题是游戏代币的无限增发最终必然稀释。
- **固定总量 + 通缩销毁**：部分链游通过税收/销毁机制维持通缩（如部分 DeFi 代币的 burn 机制），但链游场景下销毁难以持续——产出速率通常远高于销毁速率。
- **动态调控**：部分项目尝试根据通胀率动态调整产出速率（如以太坊 EIP-1559 的 base fee burn），但链游场景下经济模型的可编程性受限于合约升级机制。

## 崩盘机制

链游经济的崩盘机制通常是**死亡螺旋**：

1. 新玩家入场放缓，需求下降
2. 产出代币的抛压超过需求，代币价格下跌
3. 早期投资者抛售代币，加速下跌
4. 玩家失去激励，停止游戏
5. 产出进一步下降，但代币价格已经崩盘，无法恢复

Ronin 桥事故是链游崩盘的典型催化——不是经济模型本身崩盘，而是桥的安全事故直接摧毁了玩家对项目的信心。

## Ronin 桥事故

- **时间**：2022 年 3 月 23 日
- **损失**：约 6.2 亿美元（当时估值），包括 20,000 个 ETH、1500 万 USDC、1500 万 WBNB、500 万 USDC
- **攻击方式**：黑客伪造交易签名，通过 Ronin 桥将未铸造的代币发送到以太坊主网
- **归因**：攻击者被关联到朝鲜 Lazarus Group
- **影响**：Axie Infinity 经济体系此后未能恢复，SLP 价格长期低迷
- **出处**：[BBC·Ronin Network: What a $600m hack says about the state of crypto](https://www.bbc.com/news/technology-60933174)

## 与 DeFi 经济的对比

| 维度 | 链游经济 | DeFi 经济 |
| --- | --- | --- |
| 资产类型 | NFT + 代币 | 仅代币 |
| 产出激励 | 游戏行为（对战/跑步） | 流动性提供/借贷 |
| 消耗机制 | 繁殖/升级/修复 | 销毁/手续费 |
| 投机成分 | 高（NFT 二级市场） | 高（杠杆/套利） |
| 崩盘风险 | 死亡螺旋 + 安全事故 | 挤兑 + 预言机操纵 |
| 与 DeFi 关联 | 部分链游集成 DeFi | 原生 DeFi |

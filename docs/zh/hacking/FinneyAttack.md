# Finney 攻击

Finney攻击是一种针对区块链，特别是比特币网络的攻击方式，由比特币先驱Hal Finney描述。这个攻击需要以下条件：

1. **攻击者控制一个矿池**：攻击者需要有足够的算力，以便能找到一个区块。
2. **商家接受未确认交易**：商家需要在交易未被确认之前接受这笔交易。例如，在商家收到一笔交易后立即提供商品或服务，而不等待交易在区块链上确认。

### 攻击步骤

1. **攻击者生成一笔交易**：攻击者生成一笔支付给自己的交易A，但不广播这笔交易到网络中。此时，交易A仍然在攻击者的控制之下。
2. **矿工挖出一个区块**：攻击者在生成交易A的基础上，继续挖矿。当攻击者成功挖出一个区块时，将这笔交易A包含在这个区块中，但并不立即广播这个区块。
3. **生成并发送另一笔交易**：攻击者生成另一笔交易B，这笔交易是支付给商家的，并广播到比特币网络中。此时，商家在看到交易B时，可以选择提供商品或服务。
4. **广播带有交易A的区块**：在商家提供商品或服务后，攻击者立即广播之前挖出的包含交易A的区块。这时，交易A将被添加到区块链中，而交易B因为使用相同的输入将被视为无效的双花交易。

### 攻击成功的条件

- **攻击者必须拥有一定的算力**：虽然攻击者并不需要像51%攻击那样控制网络的大部分算力，但也需要有一定的算力来确保能够找到一个区块。
- **商家接受未确认交易**：如果商家总是等待交易被确认，那么Finney攻击将无法成功。

### 防御措施

1. **等待交易确认**：最简单和最有效的防御措施是等待交易被区块链网络确认（通常至少6个确认），特别是对于大额交易。
2. **减少未确认交易的处理**：商家可以选择减少或避免在收到未确认交易时立即提供商品或服务。
3. **增加监控机制**：商家可以使用区块链监控工具，及时了解网络中出现的未确认交易和双花交易的情况。

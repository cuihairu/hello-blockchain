# 女巫攻击

女巫攻击（Sybil Attack）得名于小说《女巫》中的多重人格主角：**一个攻击者伪造大量身份/节点，试图以"人多势众"左右对等网络中的投票、路由与共识**。在无需许可的网络里，身份几乎免费，"一票一身份"即可被无限稀释——女巫防御因此是所有开放网络协议的第一道门槛。女巫节点还常作为前置手段，进一步实施日蚀攻击或制造网络分裂。

## 攻击原理

1. **身份伪造**：
   - 攻击者批量生成节点公钥或账号，伪装成大量"独立参与者"。
   - 在投票类协议（链上治理、二次方资助）中放大话语权；在 P2P 网络中占据目标节点的路由表。
2. **目标性包围**：
   - 精心构造 Peer ID 靠近目标节点（Kademlia 类 DHT 中按 XOR 距离选桶），把目标节点的路由表/候选出块见证人名额填满己方节点，形成日蚀攻击（Eclipse Attack）。
3. **共识权重稀释**：
   - 对以"节点数"计权的系统（无质押的 PoA 名单外网络、GossipSub 评分、匿名通信 layer），女巫节点可联手审查、延迟或篡改消息。
4. **放大其他攻击**：
   - 大量女巫节点同时指控/举报（评分系统刷差评）、垄断中继（闪电网络路由费操纵）、增加跨链桥验证人集合渗透面（见[跨链桥攻击](/hacking/CrossChainBridgeAttack)）。

## 防御思路：给身份加价

| 机制 | 思路 | 代表 |
| --- | --- | --- |
| 工作量证明 | 身份 = 烧电的算力 | Bitcoin（见 [PoW](/consensus/POW)） |
| 权益质押 | 身份 = 锁仓押金，作恶罚没 | Ethereum、Avalanche |
| 身份认证 | 许可集合、PKI 证书 | 联盟链、FISCO BCOS |
| 资源校验 | 存储/带宽等真实资源门槛 | IPFS DHT、Filecoin |
| 图/声誉分析 | 社会信任图抵御批量假号 | 页面排名类 P2P 评分 |
| 结构性隔离 | 限制单一下游节点的影响面 | Bitcoin 的"8 出链连接"、GossipSub topic 评分 |

## 与网络分裂攻击的关系

女巫攻击与网络分裂攻击（Network Partition Attack）经常被混为一谈，但目标不同：女巫攻击制造**虚假的多数**，网络分裂攻击切断**真实节点间的通信**，使账本出现互相独立的分区。两者常常串联：先用女巫节点包围目标（日蚀），再让被包围节点看到的"全网"只是攻击者的假象——共识层面则表现为分叉、双花与数据不一致。防御上，前者靠身份成本，后者靠多样对端连接、检查点与跨区冗余（另见[共识分叉攻击](/hacking/ConsensusForkAttack)）。

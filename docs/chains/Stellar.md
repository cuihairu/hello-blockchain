# Stellar 恒星币

Stellar 是一个开源的区块链支付网络，旨在通过降低跨境支付成本和提高交易速度来连接银行、支付系统和人们。以下是对Stellar项目的详细介绍：


## 白皮书与规范

《The Stellar Consensus Protocol: A Federated Model for Low-Finality Contracts》——David Mazieres，2015-05/2016（[stellar-consensus-protocol.pdf](https://www.stellar.org/papers/stellar-consensus-protocol.pdf)，FBA 仲裁切片模型）；Stellar 白皮书 2014（Jed McCaleb）。主网 2014-07-31 上线。

## 解决什么问题

跨境结算要快、要便宜、还要让银行与个人都能接——不靠挖矿、不靠全量验证人两两通信。

## 技术成果与贡献

- **SCP/FBA**：仲裁切片（quorum slice）的开放成员制 BFT——节点自选信任组合，全网一致性由切片相交保证，见 [FBA](/consensus/FBA) 与 [RPCA](/consensus/RPCA) 的同族对照。
- **锚点网关模型**：法币出入金由锚点承兑——把合规外包给专业机构。
- **固定极低费用 + 3-5 秒终局**：支付级体验，见[结算层](/layers/Settlement)的最终性权衡。
- **Soroban（2023-24）**：Rust/WASM 合约运行时加入。

## 局限与公开事故

- quorum slice 配置复杂且易错——安全依赖配置正确；生态采用有限。
- 公开事故：2017-11-27 版本升级缺陷致全网停摆约 2 小时（紧急降级修复并发赏金）；2019-05-14 验证人 bug 致全网停摆约 2 小时。

## 补充说明
### Stellar 的基本概述

1. **背景和目标**：
   - Stellar 是由 Jed McCaleb 和 Joyce Kim 在2014年创建的区块链项目，最初是为了解决传统银行和金融机构之间高昂的跨境支付费用和时间延迟问题。它的目标是通过去中心化的网络实现快速、安全和低成本的货币交换。

2. **核心技术和架构**：
   - **Consensus Protocol**：Stellar 使用一种名为 Stellar Consensus Protocol（SCP）的共识协议。SCP 是一种去中心化、容错和高效的共识机制，允许网络节点通过互联网协商一致地达成交易确认。
   - **分布式账本**：Stellar 的分布式账本记录所有的交易和账户余额信息，这些信息通过网络中的节点共享和同步，确保整个网络的一致性和安全性。

3. **支付网关和资产发行**：
   - Stellar 允许用户通过支付网关（Anchors）在其网络上发行和交换各种资产，如法定货币、加密货币和商品代币。这使得用户可以在Stellar网络上进行快速和低成本的资产转移和交换。

4. **去中心化交换和DEX**：
   - Stellar 包括一个内置的去中心化交换（Decentralized Exchange, DEX），允许用户直接在网络上交换资产，而无需通过中介机构。DEX 提供了流动性和价格发现，支持各种资产的市场交易。

5. **应用场景和生态系统**：
   - Stellar 的主要应用场景包括跨境支付、微支付、金融包容性和资产代币化。它通过降低交易成本和增加交易速度，为全球范围内的个人、企业和金融机构提供了一种有效的支付解决方案。
   - Stellar 还支持开发者构建和部署去中心化应用程序（DApps），这些应用程序可以利用其支付和资产交换功能来创建新的金融服务和工具。

6. **发展和未来展望**：
   - Stellar 的发展团队和社区致力于推动其网络的扩展性、安全性和用户体验。未来，Stellar 可能会继续优化其技术架构、增强网络的互操作性，并进一步推广其在全球支付和金融服务领域的应用。

### 总结

Stellar 是一个专注于跨境支付和金融包容性的开源区块链项目，通过其高效的共识协议和去中心化的交换平台，为全球用户提供了一个快速、安全和低成本的支付解决方案。其支持多种资产的发行和交换，并通过内置的去中心化交换提供了市场流动性和资产流通的基础设施。Stellar 在金融科技创新和区块链应用开发中有着广泛的应用和前景。
